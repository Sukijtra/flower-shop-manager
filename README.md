# 1. ชื่อโครงงาน

**Flower Shop Manager (ระบบจัดการข้อมูลร้านดอกไม้)**

# 2. ปัญหาและที่มา

ลูกค้าอาจประสบปัญหาในการค้นหาดอกไม้ที่เหมาะสมกับโอกาสต่าง ๆ เนื่องจากข้อมูลเกี่ยวกับดอกไม้ เช่น ชื่อ ราคา และประเภท อาจไม่ได้ถูกจัดเก็บไว้อย่างเป็นระบบและอยู่ในที่เดียวกัน

# 3. แนวทางการแก้ไขปัญหา

**Flower Shop Manager** เป็นแอปพลิเคชันภาษา Python ขนาดเล็กที่ช่วยดึงข้อมูลดอกไม้จาก API รองรับการค้นหาดอกไม้ การเพิ่มข้อมูลดอกไม้ และจัดเก็บข้อมูลดอกไม้ไว้ในไฟล์ JSON ภายในเครื่อง เพื่อให้สามารถนำข้อมูลกลับมาใช้งานได้ในภายหลัง

# 4. ขอบเขตด้านระบบ

**เครื่องมือ / การวิเคราะห์และการจัดการข้อมูล**

# 5. API ที่ใช้

* **ชื่อ API:** JSONPlaceholder Mock API
* **ประเภทข้อมูล:** ข้อมูลดอกไม้ เช่น ชื่อดอกไม้ ราคา และประเภท
* **HTTP Methods:** GET และ POST

# 6. แผนการจัดเก็บข้อมูล

* **รูปแบบ:** จัดเก็บข้อมูลในไฟล์ JSON
* **รายละเอียด:** จัดเก็บข้อมูลดอกไม้ไว้ในไฟล์ `data/flowers.json`

# 7. รูปแบบการพัฒนา

ใช้หลักการเขียนโปรแกรมเชิงฟังก์ชัน โดยแบ่งการทำงานออกเป็นฟังก์ชันอย่างชัดเจน เช่น

* ฟังก์ชันสำหรับเรียกข้อมูลจาก API
* ฟังก์ชันสำหรับจัดเก็บข้อมูล
* ฟังก์ชันสำหรับค้นหาข้อมูลดอกไม้
* ฟังก์ชันสำหรับแสดงข้อมูลดอกไม้

การแบ่งฟังก์ชันช่วยให้โค้ดเป็นระเบียบ เข้าใจง่าย และสามารถแก้ไขหรือพัฒนาต่อได้สะดวก

# 8. บทบาทและหน้าที่

* **ผู้จัดการโครงงาน / ผู้ดูแล CI-CD:** ดูแล Repository บน GitHub และจัดการ GitHub Actions
* **ผู้ทดสอบอัตโนมัติและ QA:** สร้าง Test Case ด้วย pytest และตรวจสอบคุณภาพโค้ดด้วย flake8
* **นักพัฒนาหลัก:** พัฒนาการเชื่อมต่อ API ระบบค้นหา และการจัดเก็บข้อมูล

**กรณีเป็นโครงงานเดี่ยว:** นักศึกษาจะรับผิดชอบทั้ง 3 บทบาท โดยแบ่งหน้าที่ตามช่วงของการพัฒนาโครงงาน

# 9. ฟังก์ชันหลักของระบบ (MVP)

1. ดึงข้อมูลดอกไม้จาก API ด้วย HTTP GET
2. ค้นหาดอกไม้จากชื่อและบันทึกข้อมูลลงในไฟล์ JSON
3. เพิ่มข้อมูลดอกไม้ใหม่ผ่าน API ด้วย HTTP POST

# 10. ฟังก์ชันเพิ่มเติม (Stretch Features)

* กรองข้อมูลดอกไม้ตามประเภท
* คำนวณราคาเฉลี่ยของดอกไม้
* ส่งออกข้อมูลดอกไม้เป็นไฟล์ CSV

# 11. เกณฑ์การประเมิน

* API สามารถทำงานด้วย HTTP GET และ POST
* ระบบสามารถจัดการข้อผิดพลาดจาก API ได้
* ระบบสามารถอ่านและแปลงข้อมูล JSON ได้อย่างถูกต้อง
* ข้อมูลดอกไม้สามารถจัดเก็บไว้ในไฟล์ JSON ได้
* โค้ดเป็นไปตามมาตรฐาน PEP 8 และสามารถตรวจสอบด้วย flake8
* Unit Test สามารถทำงานผ่าน pytest ได้
* GitHub Actions สามารถทำงานทดสอบและตรวจสอบโค้ดโดยอัตโนมัติ
* README มีรายละเอียดเกี่ยวกับการติดตั้งและวิธีใช้งานระบบ
